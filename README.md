# 🏡 Imperial Residencies – Luxury Real Estate Website

A modern, responsive luxury real estate website built using HTML, CSS, Bootstrap 5, and JavaScript. The website is inspired by premium real estate brands such as Christie's International Real Estate and showcases luxury properties with an elegant, user-friendly interface.

---

## 📌 Project Overview

Imperial Residencies is a front-end real estate website designed to provide a premium browsing experience for luxury property buyers. It features elegant layouts, smooth animations, responsive design, interactive property listings, and modern UI components.

2. Open the project folder.

3. Open `index.html` in your browser.
